# LearnLoop 产品设计文档

> 版本：v0.1　|　日期：2026-11-24　|　状态：草案

---

## 1. 产品定位

**一句话**：面向中国本科生的「学习管理 + 保研规划」个人工作台，把散落的课程资料、错题、复习计划、加分材料收进同一个本地空间，用 AI 把"整理"和"规划"这两件最耗时间的事自动化。

**目标用户**：准备保研的本科生（大二～大四为主），手上有大量课程资料，同时在攒竞赛、科研、实践、志愿等加分材料。

**核心价值**：

| 价值 | 说明 |
|---|---|
| 不丢 | 资料统一归档，批注与原文位置绑定，随时可回看 |
| 会学 | 错题 → 变式 → 导图 → 复习计划，形成可执行的学习闭环 |
| 算得清 | 综测加分自动识别、自动累加、可模拟，不再手算 Excel |

**设计原则**：

1. **本地优先**：数据默认只存在本机，不依赖账号体系，支持一键备份/恢复。
2. **AI 产出必可校对**：所有 AI 结果以"草稿"形态落地，用户确认或修改后才生效，不直接写死。
3. **闭环优先于功能数量**：先把一条完整链路做通，再横向扩功能。
4. **单机自用**：首版不做多用户、不做社交、不做云端同步。

---

## 2. 核心闭环

```
资料上传 ──▶ 阅读批注 ──▶ 错题沉淀 ──▶ 知识导图 ──▶ 考前复习计划
   ▲                │              │              │
   │                └──────────────┴──────────────┘
   │                        知识沉淀回流
   └──────────── 综测规划（另一条独立主线）────────────
```

两条主线共用同一套"资料 / 证据"底座：

- **学习主线**：资料 → 批注 → 错题 → 导图 → 复习计划
- **保研主线**：规则 → 加分材料 → 识别归类 → 总分与模拟

## 3. 功能结构

### 3.1 学科学习模块

**学科管理**
- 自定义学科（名称、颜色、图标），可增删改
- 每个学科下挂：资料、错题、导图、考试

**资料与批注**
- 上传 PDF / 图片 / Word / PPT，在线阅读
- 多色高亮、下划线、自由画笔、文字批注
- 批注锚定到原文位置，滚动/缩放不漂移
- 批注可汇总导出（按学科 / 按资料）

**错题本**
- 三种录入：文字、图片（拍照/截图）、文件
- 图片与文件先 OCR 转文字，再结构化为"题干 / 选项 / 答案"
- AI 生成**同类变式题**（可指定难度、数量、是否给解析）
- AI 分析**错误点**与**正确解法**，并打知识点标签
- 错题可按知识点、掌握状态筛选重组

**思维导图**
- 从资料 / 笔记 / 错题一键生成导图
- 在线编辑节点，可导出图片与大纲文本
- 导图与学科绑定，可被复习计划引用

**考试与复习计划**
- 录入考试信息：科目、日期、范围、目标分
- 自动汇总该学科的**资料、错题、导图**
- 生成**考前复习清单**（按知识点权重排序）与**每日计划**（按剩余天数分配任务）
- 每日任务可勾选打点，进度可视化

### 3.2 保研模块

**综测子模块**

- **规则配置**（用户在自己网页里录入）
  - 支持文字 / 文件 / 图片三种方式录入学校或学院的综测细则
  - 图片与 PDF 走 OCR，再由大模型转成**结构化规则**：维度（德智体美劳）→ 子项 → 分值 → 上限 → 认定条件
  - 以**可编辑表单**呈现，用户确认后生效；不同学院可并存多套规则
- **加分材料录入**
  - 同样支持文字 / 文件 / 图片
  - 自动识别所属维度与子项、折算分数，并给出**得分依据**（命中哪条规则、为什么是这个分值）
  - 支持人工改判，改判后重新累加
- **总分与模拟**
  - 按维度汇总、给出总分与各部分占比
  - 分数模拟：勾选/取消材料、调整待定项，实时预览总分变化与目标差距
- **材料归档**
  - 原始凭证留档，可回看、可导出打包

### 3.3 全局音乐播放器

- 全站悬浮的迷你播放条 / 悬浮球，切页不中断
- 上传本地音乐，建立播放列表
- 上一首 / 下一首 / 进度 / 音量
- 循环（列表循环、单曲循环）与随机播放

### 3.4 通用能力

- 全局搜索：跨学科、跨资料、跨错题检索
- 设置中心：API Key 配置、主题（浅色/暗色）、数据备份与恢复
- 一键导出/导入全量数据（便于换机与备份）

## 4. 页面结构

```
工作台（首页）
├── 今日任务 / 复习倒计时 / 最近资料
├── 学科
│   ├── 学科详情 → 资料 | 错题 | 导图 | 考试

├── 复习计划
├── 综测
│   ├── 规则配置

└── 设置
```

全局悬浮元素：音乐播放器（常驻）、快捷新建（资料/错题/材料）。

## 5. AI 能力与边界

| 场景 | 能力 | 说明 |
|---|---|---|
| 图片/扫描件 | OCR | 转文字并保留坐标，可定位原文 |
| 错题录入 | 结构化 + 题目生成 | 生成变式题、错因分析、解法 |
| 导图 | 结构化生成 | 从资料/错题抽取层级大纲 |
| 复习计划 | 规划生成 | 按剩余天数与知识点权重排期 |
| 综测规则 | 规则解析 | 文本/图片 → 结构化计分规则 |
| 综测材料 | 分类与计分 | 匹配维度子项并说明依据 |

**边界与兜底**：

- 一律要求模型返回**结构化 JSON**，解析失败则降级为"原文 + 人工填写"
- 所有 AI 结果进入**草稿态**，用户可编辑、可撤销
- 关键计算（加分累加、总分）由**本地代码**完成，不交给模型算

## 6. 数据与存储

- **业务数据**：浏览器 IndexedDB（学科、资料元信息、批注、错题、导图、考试、规则、材料）
- **文件本体**：Blob 存 IndexedDB，或由本地服务落盘（大文件更稳）
- **结构化查询/统计**：本地服务内置 SQLite（`node:sqlite`，零原生依赖）
- **密钥**：仅存本地后端环境变量，不进入前端包、不进入 git
- **备份**：一键导出为压缩包，可完整恢复

## 7. 技术方向（概要）

| 层 | 选型 |
|---|---|
| 前端 | React 19 + TypeScript + Vite |
| 状态/存储 | Zustand + Dexie（IndexedDB） |
| 文档与画布 | pdfjs-dist + fabric.js |
| 导图 | mind-elixir |
| 音频 | Howler.js |
| 本地服务 | Node + Express（代理大模型、文件落盘、SQLite） |
| 大模型 | DeepSeek `deepseek-flash`（文本 + 视觉）、OCR API |

## 8. 迭代计划

| 阶段 | 内容 | 目标 |
|---|---|---|
| M1 | 框架搭建、学科管理、资料上传与在线阅读批注 | 打通"资料→批注" |
| M2 | 错题录入、变式题、错因分析、思维导图 | 打通"错题→导图" |
| M3 | 考试录入、复习清单、每日计划 | 打通"导图→计划" |
| M4 | 综测规则录入与解析、材料识别计分、分数模拟 | 打通"材料→总分" |
| M5 | 音乐播放器、全局搜索、备份恢复、整体打磨 | 体验收尾 |

## 9. 非目标（首版不做）

- 多用户、账号体系、社交分享
- 移动端原生 App（仅做响应式适配）
- 云端同步与在线协作
- 自动爬取题库与保研资讯
- 付费、会员等商业化功能

## 10. 主要风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 大模型输出不稳定 | 结构化解析失败 | JSON 校验 + 重试 + 人工兜底 |
| OCR 识别质量 | 错题/材料识别不准 | 识别结果可编辑后再确认 |
| 综测规则千校千面 | 计分对不上 | 规则可配置、可手改，不写死 |
| 大文件与批注性能 | 阅读卡顿 | 分页渲染、按需加载 |
| API 成本 | 长期使用费用 | 结果缓存，重复内容不重复调用 |
