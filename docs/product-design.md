# LearnLoop 产品设计文档

> 版本：v0.2　|　日期：2026-11-24　|　状态：草案

---

## 1. 产品定位

**一句话**：面向中国本科生的「学习管理 + 保研规划」个人工作台，把课程资料、错题、复习计划、成绩与加分材料收进同一个本地空间，用 AI 把"整理、识别、算分"这三件最耗时间的事自动化。

**目标用户**：准备保研的本科生（大二～大四为主），手上有大量课程资料，同时要维护必修课成绩、攒综测加分材料。

**核心价值**：

| 价值 | 说明 |
|---|---|
| 不丢 | 资料统一归档，批注与原文位置绑定，随时可回看 |
| 会学 | 错题 → 变式 → 导图 → 复习计划 → 今日任务，形成可执行的闭环 |
| 算得清 | 必修成绩与综测加分由文件自动识别、自动累加，改一处即时重算 |

**设计原则**：

1. **本地优先**：数据默认只存在本机，不依赖账号体系，支持一键备份/恢复。
2. **识别结果必须人工确认**：AI 只产出"草稿"，用户确认或修改后才参与计算。
3. **算分交给本地代码**：模型只负责"认字和归类"，加减乘除一律由本地计算，保证可复现、可审计。
4. **非破坏性编辑**：原始文件永不修改，批注与标记都是独立附加层；删除只删附加层，且可撤销、可从回收站恢复。
5. **闭环优先于功能数量**：先把一条完整链路做通，再横向扩功能。
6. **单机自用**：首版不做多用户、不做社交、不做云端同步。

## 2. 核心闭环

```
学习线：资料 ──▶ 批注 ──▶ 错题 ──▶ 导图 ──▶ 复习计划 ──▶ 今日任务
                                                        ▲
保研线：成绩单/加分材料 ──▶ 识别 ──▶ 确认 ──▶ 算分 ──▶ 综合成绩与模拟
                          （两条线共用同一个"录入→识别→确认"底座）
```

- **学习线**：资料 → 批注 → 错题 → 导图 → 复习计划 → 今日任务
- **保研线**：必修成绩 + 综测加分，两条子线都走"文件录入 → 识别 → 确认 → 计算"
- **共用底座**：「录入 · 识别 · 确认」是横跨所有模块的通用能力，错题、成绩单、加分材料复用同一套流程

## 3. 功能结构

### 3.1 学科学习模块

**学科管理**

- 自定义学科（名称、颜色、图标），可增删改
- 每个学科下挂：资料、错题、导图、考试

**资料与批注**

- 上传 PDF / 图片 / Word / PPT，在线阅读
- 多色高亮、下划线、自由画笔、文字批注
- 批注锚定原文位置，滚动/缩放不漂移
- **批注可删**：选中单条删除、橡皮擦按笔画擦除、一键清除本页或整份资料
- **非破坏性**：批注是独立图层，擦除只作用于批注层，原始文档一个像素都不改
- 删除与擦除支持撤销 / 重做，误删可即时恢复
- 批注可按学科、按资料汇总导出

**错题本**

- 三种录入：文字、图片、文件（统一走"录入 · 识别 · 确认"）
- AI 生成同类变式题（可指定难度、数量、是否附解析）
- AI 分析错误点与正确解法，打知识点标签
- **状态管理**：未掌握 / 已掌握 / 已归档；会了就标"已掌握"，也可保留当参考
- **可删除**：单条删除或批量删除，删除先进回收站，误删可恢复
- 若错题已被导图或复习计划引用，删除前提示影响范围，确认后再删
- 按知识点、掌握状态筛选重组

**思维导图**

- 从资料 / 笔记 / 错题一键生成
- 在线编辑节点，可导出图片与大纲文本

**考试与复习计划**

- 录入考试：科目、日期、范围、目标分
- 自动汇总该学科的资料、错题、导图
- 生成考前复习清单与每日计划（按剩余天数与知识点权重排期）
- 计划按天拆解后直接投递到主页「今日任务」

### 3.2 保研模块

保研模块下设**必修成绩**与**综测**两个子模块。二者逻辑一致：**录入文件 → 自动识别 → 人工确认 → 本地计算得分**。

#### 3.2.1 必修成绩

- **成绩来源**：上传成绩单截图 / 教务系统导出的 PDF / Excel 截图，或手动逐门录入
- **识别字段**：课程名称、课程性质（必修/选修）、学分、成绩、绩点
- **只算必修**：默认只统计必修课，选修可保留但不计入；性质识别错可在确认页改
- **计算结果**
  - 加权平均分 = Σ(成绩 × 学分) ÷ Σ学分
  - GPA：支持 4.0 / 5.0 / 百分制，公式可按学校配置
  - 总学分、已修门数
- **重修 / 补考规则**：取最高分或取最新分，可配置
- **手动维护**：任何一门课都可增删改，改完立即重算
- **专业排名**：无权威数据来源，提供手动填写

#### 3.2.2 综测

- **规则配置**（用户在自己网页里录入）
  - 支持文字 / 文件 / 图片录入学院综测细则
  - 识别后转成结构化规则：维度（德智体美劳）→ 子项 → 分值 → 上限 → 认定条件
  - 以可编辑表单呈现，确认后生效；可并存多套（不同学院/学年）
- **加分材料**
  - 文字 / 文件 / 图片录入，自动识别所属维度与子项并折算分数
  - 每条给出**得分依据**（命中哪条规则、为什么是这个分）
  - 可人工改判，改判后重新累加
- **汇总**：按维度汇总，展示总分与各部分占比

#### 3.2.3 保研综合成绩与模拟

- **权重配置**：必修成绩与综测按学校规则加权（比例可改），合成保研综合成绩
- **目标对照**：手动填写目标院校/专业的历史线，显示当前分与目标分的差距
- **分数模拟**：勾选/取消材料、调整待定项、假设某门课提分，实时预览综合成绩变化

### 3.3 录入 · 识别 · 确认

横跨全站的通用能力，所有需要"从文件里取数据"的场景都走这一套。

**三种输入方式**

| 方式 | 适用场景 |
|---|---|
| 手动输入 | 零星数据、已知准确值、识别后补漏 |
| 文件录入 | 成绩单、证书照片、综测细则 PDF |
| 粘贴文本 | 从教务系统或文档里复制的文字 |

**处理流水线**

```
文件/文本 ──▶ OCR（保留文本坐标）──▶ 大模型结构化 ──▶ JSON 校验 ──▶ 草稿
                                                          │
                                          解析失败则降级为"原文 + 手动填写"
```

**确认页（关键）**

- 左侧原文预览（PDF/图片），右侧识别结果
- 识别出的每个字段独立可编辑、可删除、可新增
- 低置信度项标黄提示，需人工过目
- 「确认入库」后才参与计算；未确认的进"待确认"队列，不污染总分

**可追溯**

- 每条数据记录来源文件、识别时间、是否人工修改过
- 算分出错时能一路回溯到原始凭证

### 3.4 主页与今日任务

**主页内容**

- 最近一场考试的倒计时
- 今日任务列表与完成度
- 最近编辑的资料、待确认的识别结果
- 当前保研综合成绩概览

**复习计划与今日任务联动**

- 复习计划按考试日期**倒排**，自动拆成每日任务
- 今日任务 = 计划中「今天」的任务 + 手动添加的任务 + 逾期未完成（自动顺延）
- 勾选完成 → 回写计划进度 → 未完成的自动重排到后续日期
- 计划做了调整（改考试日期、增删知识点），今日任务同步刷新

### 3.5 全局音乐播放器

- 全站悬浮的迷你播放条 / 悬浮球，切页不中断
- 上传本地音乐，建立播放列表
- 上一首 / 下一首 / 进度 / 音量
- 循环（列表循环、单曲循环）与随机播放

### 3.6 通用能力

- 全局搜索：跨学科、跨资料、跨错题、跨材料检索
- 设置中心：API Key、主题（浅色/暗色）、数据备份与恢复
- 一键导出/导入全量数据

## 5. AI 能力与边界

| 场景 | 能力 | 说明 |
|---|---|---|
| 成绩单 / 证书 | OCR | 转文字并保留坐标，可定位原文 |
| 成绩单 | 字段抽取 | 课程、性质、学分、成绩结构化 |
| 错题 | 结构化 + 题目生成 | 生成变式题、错因分析、解法 |
| 导图 | 结构化生成 | 从资料/错题抽取层级大纲 |
| 复习计划 | 规划生成 | 按剩余天数与知识点权重排期 |
| 综测规则 | 规则解析 | 文本/图片 → 结构化计分规则 |
| 综测材料 | 分类与计分 | 匹配维度子项并说明依据 |

**边界与兜底**：

- 模型一律返回**结构化 JSON**，解析失败降级为"原文 + 人工填写"
- 所有识别结果先进入**草稿态**，确认后才入库
- **加权平均分、加分累加、综合成绩由本地代码计算**，模型不参与算术

## 6. 数据与存储

- **业务数据**：浏览器 IndexedDB（学科、资料元信息、批注、错题、导图、考试、课程、规则、材料）
- **批注独立存储**：高亮、笔迹、文字批注作为独立图层保存（位置、类型、颜色、内容），与原始文件分离；删批注不触碰原文件
- **软删除**：错题、批注、材料删除后进回收站保留原记录，可恢复或彻底清除
- **文件本体**：小文件存 IndexedDB，大文件（整本 PDF、成绩单）由本地服务落盘
- **计算与统计**：本地服务内置 SQLite（`node:sqlite`，零原生依赖）
- **密钥**：仅存本地后端环境变量，不进前端包、不进 git
- **备份**：一键导出压缩包，可完整恢复

## 10. 主要风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 成绩单识别错行/错列 | 加权分算错 | 确认页逐行核对 + 来源可追溯 |
| 大模型输出不稳定 | 结构化解析失败 | JSON 校验 + 重试 + 人工兜底 |
| 综测规则千校千面 | 计分对不上 | 规则可配置、可手改，不写死 |
| OCR 对模糊照片效果差 | 识别率低 | 提示重拍，支持手动补录 |
| 误删批注或错题 | 复习痕迹丢失 | 独立图层 + 撤销重做 + 回收站 |
| API 成本 | 长期使用费用 | 结果缓存，同一文件不重复识别 |
